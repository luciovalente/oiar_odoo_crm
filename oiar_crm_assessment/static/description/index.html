OIAR Assessment for CRM

From the lead to the implementation assessment, without leaving Odoo.

Start an OIAR Odoo implementation assessment from a CRM lead. The customer is interviewed on OIAR; the approved report comes back to the lead.

  • Start from the lead: one button, with a preview of exactly what is sent.
  • Signed webhook: the report is attached to the lead, announced in the chatter, with a follow-up activity and an optional stage change.
  • Status: the state of the assessment is refreshed on the lead.
  • Safe by design: HMAC signature with replay window, duplicate deliveries ignored, report stored as a file and never rendered as HTML.

Requires an OIAR account and an API key. Self-hosted or Odoo.sh (custom modules are not available on Odoo Online).
