OIAR Assessment for CRM

Start an Odoo implementation assessment from a lead and get the report back on the lead.

What it does

  • Start from the lead. A "Start OIAR assessment" button opens a confirmation window that shows exactly what is sent. Nothing leaves Odoo before the user confirms.
  • Reuses what the lead already holds. Company, language, industry, company size, current systems, desired timeline, tags (Odoo apps of interest) and internal notes (problems to solve).
  • Report back on the lead. When the report is approved on OIAR it is attached to the lead (Markdown, plus PDF when available), a note is posted in the chatter, an activity is scheduled for the salesperson and the lead can move to a stage of your choice.
  • Status on the lead. The state of the assessment is refreshed automatically and on demand.

External service and data

This module needs an OIAR account and an API key: the assessment runs on the OIAR platform, not in Odoo. The module itself needs no activation key and your data stays yours.

Data sent to OIAR, only after the user confirms on the lead: company name, language, a reference to the lead, and, when filled, industry, company size, current systems, desired timeline, lead tags and lead internal notes. OIAR sends back the approved report to a webhook of your Odoo, accepted only when signed with the shared secret.

Setup in three steps

  1. Install the module and fill the OIAR section of the CRM settings (API URL and API key).
  2. Register the webhook URL shown in the settings on your OIAR account and paste the secret in the settings.
  3. Open a lead and press "Start OIAR assessment".

Works on Odoo.sh and on-premise installations. Custom modules are not available on Odoo Online. The webhook URL must be reachable over HTTPS from the internet.

Security

  • The webhook verifies an HMAC-SHA256 signature and rejects stale requests (5 minute window).
  • Repeated deliveries are recognised and handled once.
  • The report is stored as a file and never rendered as HTML.
